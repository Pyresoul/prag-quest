# Prag Quest

Reiseplaner-PWA für Prag: Kingdom-Come-Deliverance-Schauplätze, Bars, vegane/vegetarische Restaurants. Kein Build nötig, reine statische Dateien.

Lokal testen: `python3 -m http.server 8080` und `http://localhost:8080` öffnen.
Online: GitHub Pages (Settings → Pages → Branch `main`, Ordner `/ (root)`).

Orte und Koordinaten stehen in `data.js` und sind Näherungswerte. Öffnungszeiten und vegane Optionen vor Ort prüfen.
